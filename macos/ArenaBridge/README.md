# Arena Bridge.app

Нативное приложение для моста: окно настройки и журнала плюс menubar-контроль службы.

## Сборка

```bash
xcode-select --install          # один раз, если ещё нет Xcode CLT
cd macos/ArenaBridge
./build.sh                      # → dist/Arena Bridge.app
cp -R "dist/Arena Bridge.app" /Applications/
```

Собирается под текущую архитектуру (`ARCH=x86_64` для Intel, `ARCH=arm64` для Apple Silicon).
Нужен только Swift из Command Line Tools — Xcode целиком не требуется.

## Что внутри окна

| Блок | Что делает |
| --- | --- |
| Статус | запущен/остановлен, версия, режим, число инструментов, публичный адрес, состояние Telegram |
| Управление | «Запустить» / «Остановить» (служба `ai.arena.bridge` в launchd) и «Настроить…» |
| Подтверждения | ожидающие запросы агента с кнопками «Разрешить» / «Отклонить» |
| Журнал | последние записи журнала, фильтр по инструменту и «Сохранить…» в файл |

## Menubar

Иконка показывает состояние службы: `link-2` при работе, `link-2-off` при остановке и
анимированные точки во время запуска или остановки. Меню содержит Start/Stop, Copy Prompt,
Open и Quit. Закрытие основного окна убирает приложение из Dock, но оставляет menubar-доступ.

## Настройка

«Настроить…» спрашивает туннель (ngrok/cloudflared), зарезервированный домен, authtoken,
папки для агента и Telegram (токен бота и chat id) — и собирает конфиг, службу и запуск
одной кнопкой.

Приложение работает с локальным API моста (`127.0.0.1:8787`) и читает
`~/.arena-bridge/config.json`; ничего не пишет в интернет.
