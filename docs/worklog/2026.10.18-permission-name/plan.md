# Запись разрешений под именем приложения

## Задача

В «Системные настройки → Конфиденциальность и безопасность → Запись экрана и системного аудио»
строка нашей службы называется `node`. Нужно, чтобы называлась **Arena Bridge**.

Это не переименование пункта «Вход» — он уже называется как приложение. Это идентичность
процесса для TCC: macOS пишет разрешение на тот процесс, который стоит сверху в дереве, и
показывает имя его бандла.

## Что нашли

- Ответственность в macOS наследуется вниз по дереву процессов и переназначается наверху, у
  launchd. Поэтому процесс, запущенный из node, получает разрешение node.
- Пробник на реальном Mac: `launchd → бинарник внутри .app-бандла → node → захват экрана`
  записывает в TCC клиента с **bundle id** (`client_type = 0`), а не путь к node
  (`client_type = 1`). Бандл и его содержимое — вот что показывает система.
- Живой прецедент: проект **stim** закрыл ту же задачу подписанным host-app вместо node.

## Решение

Маленький помощник внутри уже существующего бандла:

```
Arena Bridge.app/Contents/Helpers/arena-bridge-agent
```

- отдельный исполняемый файл, не второе приложение и не основной бинарник SwiftUI;
- запускает заданную программу, передаёт окружение, stdout и stderr;
- передаёт ребёнку SIGTERM и SIGINT, ждёт его и завершается с его кодом — launchd с `KeepAlive`
  перезапускает службу как раньше;
- не создаёт GUI, иконку в доке, фоновых служб и новых настроек.

`src/service.mjs` и `arena_bridge/service.py` ищут бандл (`ARENA_BRIDGE_APP`, `/Applications`,
`~/Applications`), проверяют helper и, если он есть, пишут в plist

```
ProgramArguments = [helper, node, cli, tunnel, ...]
```

иначе — прежний wrapper. Установка из командной строки не зависит от наличия приложения.

## Проверка

- Node и Python: с временным тестовым бандлом — helper стартует и получает верные аргументы
  (включая параметры туннеля), без helper работает прежний путь, plist на месте и содержит
  правильную команду.
- На реальном Mac: бандл собран, helper подписан, `launchctl` запускает helper из установленного
  приложения.

## Правила

- Старая строка `node` считается возможно устаревшей: новая приходит под именем приложения, и её
  нужно один раз включить вручную. Все разрешения Screen Recording не сбрасываются.
- Правку системной базы разрешений не делаем.
